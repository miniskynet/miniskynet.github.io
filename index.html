Enterprise User Guides

Venuix — event & venue management platform

End-to-end workflow guides written in my current role at Programus Ltd. for an enterprise event and venue management platform, covering simplified event setup, seating chart maintenance mode, and booking status configuration — from high-level setup flows to granular conditional logic, written for a non-technical audience.

Read excerpt — Simplified Event Setup

To set up an Event using the Simplified Event Setup Process in Venuix:

  1. Visit the Venuix Portal and sign in using the username and password provided to you.
  2. Go to the Setup Module by clicking on the Setup button.
  3. Select Events and Products from the left side panel, then select Events from the module list.
  4. Select Add New Event, which directs you to a new page.
  5. Under the General tab, provide a name for the event, upload an image, and choose Public or Private as the event type — public events are scheduled in advance (sports, classes, courses), while private events are customer-driven (weddings, product launches).
  6. Assign a primary venue, event category, and responsible event manager from their respective drop-downs.
  7. Click Save to create the event.

The full guide also covers email templates for booking/enquiry/waitlist confirmations, facility linking, and package configuration — condensed here for length.

Read excerpt — Seating Chart in Maintenance Mode

Once the seating chart has been accessed via the Booking or Diary module, the following steps apply:

  1. Switch to maintenance mode using the toggle in the upper right corner.
  2. By default, seating categories are grouped by price band — you can also group by booking list or block.
  3. Use the search field to filter by booking reference, client name, contact name, package name, or notes.
  4. To reserve seats: select the preferred seats, click Reserve Seats, enter a note, and submit. A confirmation message displays on success.
  5. To free up seats: select allocated seats and click Un-allocate, confirming in the pop-up that follows.
  6. The freeze option prevents selected seats from being un-allocated while other actions are performed — useful for holding a block during a multi-step booking process.

Note: "Using the Allocate button will automatically assign the seats starting from the top left-most available section." — an inline callout preserved from the original guide.

Read excerpt — Booking Status Configuration

To add a new booking status:

  1. From Setup → Bookings → Booking Statuses, click Add New Booking Status.
  2. Select a Parent Booking Status to establish the status hierarchy — this determines the progression path a booking can follow.
  3. Configure checkboxes for whether the status reserves stock, requires specific user rights to edit, requires a linked client, or should be hidden from the public portal.
  4. Under the Approval tab, optionally require approval to enter this status, with separate drop-downs for the approved and rejected outcome statuses.
  5. If the parent status is Provisional or Quotation, an Expiry tab appears, letting the status auto-expire after a set number of days or relative to the event's start/end date.

This workflow demonstrates documenting conditional logic — fields and tabs that only appear based on earlier selections — clearly enough for a non-technical admin to configure correctly.

Thesis, 2024

Bright Horizons — Procedurally Generated Serious Game to Promote Learning in Individuals Affected by Trisomy-21

Final year undergraduate thesis for my BEng (Hons) at Westminster — contextualizing a research problem for a broad audience, then explaining a Unity3D/C# implementation and a regression model in structured, precise language.

Read excerpt — Abstract

The serious game "Bright Horizons" uses a procedurally generated approach to level design, producing a unique experience each playthrough to maximize engagement for individuals affected by Trisomy-21 (Down syndrome), who are strong visual learners. A regression model calculates ideal activity engagement time from gene expression data, while learning resources — numbers, letters, and colors — are distributed throughout the gameplay loop so players can learn while engaged.

Read excerpt — System implementation

The solution has two components: the game, built in Unity3D with C# logic scripts, and a regression model. Key scripts include a Procedural_Generation script that builds the terrain, places collectibles, and positions the finish line in a safe zone each run, alongside movement, life-cycle, and menu scripts.

The regression model was trained on medical data from four Excel sheets of gene expression changes, consolidated into a dataset of 10,000+ entries using pandas, then used to predict ideal activity engagement times consumed by the game engine at runtime.
